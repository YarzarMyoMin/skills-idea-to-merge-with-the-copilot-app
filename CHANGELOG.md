# Changelog

All notable changes for Mona's Bookmark Manager.

## v1.0.0 - 2026-08-08

### Added
- 🔖 Add, view, and remove bookmarks (title + URL) via a simple list UI.
- 💾 Persistence using browser localStorage so bookmarks survive reloads.
- 🧭 Open bookmarks in a new tab from the list.
- ✨ Basic client-side sorting and lightweight UX for quick bookmarking.
- 📄 ROADMAP.md added to the repository root to track planned features and risks.

### Known issues & limitations
- ⚠️ LocalStorage is the only persistence; clearing browser data will lose bookmarks.
- ⚠️ No edit flow yet; updating title/URL/tags is not implemented in v1.
- ⚠️ No tags/folders, import/export, or sync — planned in future releases.

### Notes
This is an initial, documentation-inclusive v1 aimed at shipping a minimal, usable bookmarking experience and a clear roadmap for follow-up work.
